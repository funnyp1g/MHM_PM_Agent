# PRD 撰写规范

按本技能产出高质量、可落地、与产品知识库一致的中文 Markdown PRD。

## 业务优先原则

PRD 首先回答“为什么做、为谁做、解决什么问题、用户怎么用、业务如何判断成功”。技术实现只写到能支撑产品决策和研发理解的程度，不把 PRD 写成接口文档、数据库设计或技术方案。

### 推荐表达顺序

1. 业务背景、现状问题和机会。
2. 目标用户、使用场景和用户价值。
3. 业务目标、成功标准和本期边界。
4. 用户流程、业务逻辑、业务规则和异常处理。
5. 功能需求、页面交互和验收标准。
6. 既有功能关联、风险、依赖和待确认项。
7. 技术备注（仅在影响产品决策时保留，可放附录）。

### 技术内容边界

- 不在正文展开 API、数据库表结构、字段类型、服务拆分、算法实现、缓存、幂等、日志实现或代码方案。
- 数据章节描述“业务上需要记录和展示什么”，不要求写技术实体和完整字段字典。
- 埋点只在用户明确需要数据指标、实验或转化分析时保留；只写业务指标和使用目的，不写完整事件参数表。
- 技术限制只有在会改变用户体验、业务规则、范围或验收结果时才写入“风险与依赖”。

## 前置条件

动笔前必须已加载 `product-knowledge` 技能并读取知识库（含 `ui/pages.md`、`ui/design-system.md` 和最新 `ui/device-observation-*.md`）。PRD 中的术语、状态、关联功能、页面结构均须与知识库一致，并标记实机依据、设计依据和待确认假设。

### 页面章节撰写规范（重要）

1. **引用页面ID**：每个页面标注 `ui/pages.md` 中的页面ID（如 `sales-create`、`home`），使用知识库统一页面名。
2. **沿袭既有页面范式**：新增/改动的页面结构必须沿用现有页面范式（数据卡片/红色胶囊主按钮/分类聚合/列表左滑/底部固定结算栏等），不自造布局。
3. **遵循设计系统**：颜色、字体层级、间距、组件样式遵循 `ui/design-system.md`，不引入冲突样式。
4. **适配主导航**：新页面入口需明确落在哪一导航位（顶部三Tab：首页/数据/营销，或右下角「更多功能」页）。
5. **标注待补充**：知识库页面结构缺失时标注「待补充」，不得臆造；需向用户确认。
6. **交互覆盖**：页面章节须含默认/空态/加载/禁用/错误状态与手势（点击/长按/左滑）。
7. **证据标注**：涉及页面入口、权限、字段展示或当前交互时，注明来自实机观察、设计基准还是业务确认；涉及字段、金额、数量、库存、状态或指标时，引用 `data-dictionary.md` / `metrics.md`；存在冲突时单独列出待确认项。

## 撰写原则

1. **可落地**：每个功能点必须含业务规则与验收标准；禁止「等等」「更加友好」这类不可判定描述。
2. **术语一致**：全部使用 `glossary.md` 术语；新术语先入库再使用。
3. **关联显性**：必须有「与既有功能的关联」章节，引用 `relations.md`。
4. **页面一致**：「页面与交互」章节引用 `ui/pages.md` 页面ID、沿袭 `ui/design-system.md`，与现有 App 界面保持一致。
5. **范围明确**：目标/非目标、迭代拆分清晰，防止范围蔓延。
6. **用户视角**：功能描述从用户价值出发，而非技术实现细节。
7. **验收可测**：验收标准使用 Given/When/Then，可被 QA 直接执行。
8. **业务优先**：背景、需求说明、核心业务逻辑和业务规则必须明显多于技术说明；技术内容不得喧宾夺主。

## 常见错误规避

| 错误 | 正确做法 |
|------|---------|
| 只写功能列表，无规则无验收 | 每项功能含规则、边界、验收标准 |
| 术语与知识库不一致 | 先查 `glossary.md` |
| 忽略与既有功能冲突 | 分析阶段查 `relations.md` 并显性标注 |
| 页面结构与现有 App 不一致 | 引用 `ui/pages.md` 页面ID、沿袭页面范式与设计系统，不自造布局 |
| 新增页面未适配主导航 | 明确新页面落在哪一 Tab/「更多功能」页 |
| 大而全一次交付 | 拆 MVP 与后续迭代 |
| 描述技术实现细节 | 聚焦用户价值与行为 |

## 命名与归档

- PRD 文件命名：`docs/prd/YYYY-MM-DD-<feature-slug>.md`
- 需要开发变更追踪时：在 PRD 基础上走 OpenSpec 流程（propose → apply → archive）
- 归档后同步更新产品知识库（含 `ui/pages.md` 页面结构，若新增/改版页面）
