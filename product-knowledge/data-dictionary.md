# 核心业务数据字典

> 用于约束 PRD 中的实体、字段、状态、金额和数量口径。未知内容必须标记为「待确认」，不能因为页面上出现过某个文案就推断出完整数据规则。
>
> 最后更新：2026-08-10

## 证据等级

| 等级 | 含义 | PRD 使用规则 |
|---|---|---|
| 已确认 | 用户明确确认或已在知识库中形成稳定业务规则 | 可作为业务规则使用 |
| 实机观察 | 在特定设备、账号、版本和数据状态下观察到 | 只能说明当前表现，需注明观察条件 |
| 业务假设 | 为形成可落地方案而采用的暂定口径 | 必须写入“假设与待确认项” |
| 待确认 | 证据不足或来源冲突 | 不能写成既定规则；若影响本期行为则阻塞确认 |

## 核心实体

| 实体 | 业务含义 | 当前已知字段/属性 | 当前缺口 | 主要来源 |
|---|---|---|---|---|
| 门店 | 多店版中的经营主体 | 门店名称、门店编号、地区、地址、电话、微信信息 | 门店切换后的数据隔离和跨店权限 | `features/06-settings.md`、`ui/pages.md` |
| 货品款 | 服装款式层级 | 货品名称、款号、品类、供应商、图片、拿货价、销售价、会员价 | 货品款与 SKU 的完整主键和复制规则以外字段 | `features/01-goods.md` |
| SKU | 颜色/尺码等可销售库存单元 | 款号、颜色、尺码、条码、库存数量 | SKU 编码规则、颜色/尺码归一和组合约束 | `glossary.md`、`features/01-goods.md` |
| 库存 | SKU 在门店的可用数量及货值 | 当前库存、库存货值、盘盈、盘亏 | 锁定库存、可售库存、在途库存和并发扣减规则 | `features/01-goods.md`、`features/02-purchase.md` |
| 供应商 | 货品采购来源 | 名称、电话、微信、余额、欠款、地区、市场、地址、备注 | 供应商余额/欠款的变更来源和金额口径 | `features/05-supplier.md` |
| 客户/会员 | 销售和会员运营对象 | 姓名、手机号、等级、余额、积分、优惠券、消费金额、偏好 | 会员余额、积分、优惠券的流水及失效规则 | `features/03-customer.md`、`glossary.md` |
| 销售单 | 销售开单和收款单据 | 销售时间、货品明细、数量、应收/实收、收款方式、客户、状态 | 退货、挂单、作废和欠货对库存/金额的完整状态机 | `features/04-sales.md`、`glossary.md` |
| 进货单/入库单 | 采购到货并增加库存的单据 | 供应商、入库日期、货品、数量、应付/实付金额、来源 | 单号规则、审核/作废/退货后的库存和应付影响 | `features/02-purchase.md` |
| 盘点计划 | 对库存进行盘点的业务计划 | 盘点序号、创建人、盘点前库存、盘点后库存、盘盈、盘亏、状态 | 保存、放弃、删除、完成及库存调整权限和时机 | `features/06-settings.md`、`open-questions.md` |
| 跨店调拨单 | 门店间库存转移单据 | 调出店、调入店、货品明细、数量、状态 | 发出、收货、取消各阶段的库存归属和状态规则 | `relations.md`、实机观察 |
| 补货单（SKU采购请求） | `08-replenishment` 的采购请求 | SKU、补货数量、预估金额、供应商、状态、创建人、时间 | 单号规则、已补货触发方式、与进货单的衔接 | `features/08-replenishment.md` |
| 采购进货补货单 Tab | `replenishment-tab` 的平台货品/其他货品处理能力 | 平台货品、其他货品、购物车、未处理/已处理/已失效 | 加购、处理和状态变化的完整流程 | `features/02-purchase.md`、`open-questions.md` |
| 平台采购请求 | 规划中的平台货品采购请求 | 平台货品、相似度、SKU、购物车、采购请求 | 平台目录、价格、可采购状态、订单和入库接口 | `features/09-platform-similar-purchase.md`、`open-questions.md` |

## 状态口径

| 对象 | 已确认状态/约束 | 尚未确认内容 |
|---|---|---|
| 补货单（SKU采购请求） | `待补货 → 已补货`；`待补货 → 已作废`；仅待补货可作废；提交不增加库存 | 已补货是手动标记还是进货入库联动、重复操作规则 |
| 采购进货补货单 Tab | 实机出现未处理、已处理、已失效 | 加购、处理、失效触发条件和状态回退规则 |
| 销售单 | 支持挂单、作废、退货、欠货等业务动作 | 各动作的完整状态机及库存/收款影响 |
| 进货单/入库单 | 入库是改变库存的业务动作 | 审核、作废、退货和重复入库规则 |
| 盘点计划 | 实机出现进行中、已结束；打开新增计划会自动创建空的进行中计划 | 完成、放弃、删除和库存调整规则 |
| 跨店调拨单 | 存在调拨列表和详情页面 | 调出、在途、收货、取消状态及库存归属 |

## 金额、数量和编号口径

以下规则在未补充接口/字段资料或可回滚测试数据前，统一视为待确认：

- 核心单据的编号组成、流水范围和跨门店是否唯一。
- 应收、实收、优惠、抹零、欠款、供应商余额和库存货值的计算顺序。
- 销售退货、作废、盘盈盘亏、调拨和入库对库存数量的增减时点。
- 小数精度、四舍五入/向上取整、数量上限和负数允许范围。
- 并发提交、重复点击和离线重试时的幂等规则。

## 使用与维护规则

1. 新 PRD 涉及字段时，引用实体名称，不自造同义实体。
2. 新增字段先写入本文件，并标注证据等级和来源。
3. 新增状态必须同步更新 `glossary.md`、对应功能文件和 `relations.md`。
4. 影响库存、金额或权限的未知规则必须进入 `open-questions.md`；不能只留在 PRD 临时假设中。
