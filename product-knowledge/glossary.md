# 产品术语表

> 统一业务口径，PRD 中使用术语必须与此处保持一致。有歧义时以本表为准。
> 本表包含两类知识：**服装零售行业通用知识**（第 1–9 章）与**卖货猫产品特有术语**（第 10 章起）。
> 用户/企业另有口径时，以用户指定为准；使用行业默认口径作答时须注明"按行业标准口径"。

## 商品层级

| 层级 | 说明 | 适用场景 |
|------|------|---------|
| 品类 | 牛仔裤、连衣裙等大类 | 品类销售与库存分析 |
| 款 / SPU | 同款不同色/码统称，如 A001 牛仔直筒裤 | 款式排行、波段分析 |
| 款色 | 一个款的一种颜色，如 A001 黑色 | 颜色表现、配货 |
| SKU | 款 + 色 + 码的最小货品单元 | 库存、开单、采购、调拨、退换 |

## 库存 & 滞销术语

| 术语 | 定义 | 备注 |
|------|------|------|
| SKU | 单款单色单码最小货品单元 | 服装核心统计单位 |
| 可售库存 | 当前可正常售卖的数量 | 区别于锁定/在途/残次 |
| 锁定库存 | 已被订单/流程占用 | 不包含在可售中 |
| 在途库存 | 已订货未到店 | 期货库存 |
| 残次库存 | 破损、污渍、无法正常售卖货品 | 区别于有效库存 |
| 有效库存 | 可正常陈列售卖的完整库存 | |
| 库存深度 | 单个 SKU 当前库存件数 | 深度越高越易滞销 |
| 库存广度 | 门店在售总 SKU 数量 | |
| 库龄 | 货品入库到当前存放天数 | 判定滞销核心：新品 0–7 天、浅库龄 7–45 天、长库龄（滞销）45–90 天、死库存 ≥90 天 |
| 动销率 | 周期售出 SKU 数 ÷ 总库存 SKU 数 | 畅销 >30%、平销 10%–30%、滞销 <10% |
| 售罄率 | 周期销量 ÷ 期初进货总量 | 季末 <60% = 库存积压风险 |
| 滞销款/慢销款 | 库龄 ≥45 天、动销 <10% 货品 | 行业默认口径 |
| 死库存/呆滞库存 | 库龄 90 天以上、长期 0 成交 SKU | |
| 断码库存 | SKU 仅剩 1–2 个小众尺码，无补货价值 | |
| 断码 | 同一款色下部分尺码无可售库存 | 有货尺码与零货尺码并存 |
| 齐色齐码 | 一个款的颜色与尺码完整度 | 需检查完整尺码矩阵 |
| 库存周转天数 | 平均库存 ÷ 日均销量 | 越大越压资金、滞销风险越高 |
| 库存占比 | 某品类/滞销货品成本占总库存成本百分比 | |
| 期货库存 | 提前订货未到店 | |
| 现货库存 | 门店现有实物 | |
| 调拨 | 门店间移库 | |
| 盘亏/盘盈 | 盘点实物与系统库存差额 | |
| 超储预警 | 库存深度超上限 | 阈值以企业配置为准 |
| 缺货预警 | 核心尺码低于安全备货量 | 阈值以企业配置为准 |
| 库存健康度 | 综合库龄、动销、售罄的评分 | |

## 销售业绩 & 营收术语

| 术语 | 定义 | 备注 |
|------|------|------|
| GMV | 成交总金额（含折扣、退款前总额） | |
| 实收营业额 | 扣除退款、优惠券后实际收款 | |
| 连带率 | 销售总件数 ÷ 成交单数 | 导购搭配能力核心指标 |
| 客单价 | 实收总额 ÷ 成交单数 | |
| 件单价 | 实收总额 ÷ 销售总件数 | |
| 坪效 | 每平方销售额 | |
| 人效 | 单导购/全员平均销售额 | |
| 转化率 | 进店客流 → 成交客户占比 | |
| 复购率 | 周期内二次及以上消费客户占比 | |
| TOP 款 | 销量/销售额排名靠前爆款 | |
| 长尾款 | 销量极低、占 SKU 多数、贡献少量营收 | |
| 折损/折扣率 | 实收金额 ÷ 吊牌总金额 | 越低打折力度越大 |
| 毛利额 | 销售额 − 进货成本 | |
| 毛利率 | 毛利额 ÷ 销售额 | |
| 净毛利 | 再扣残次、损耗、折扣 | |
| 促销折让 | 满减、特价、买赠带来的营收损失 | |
| 环比 | 对比同期前一区间 | |
| 同比 | 对比去年同期 | |

## 常见商品属性（品类/版型/长度/面料/波段）

- **品类**：T 恤、衬衫、卫衣、针织衫、西装、风衣、羽绒服、半身裙、连衣裙、牛仔裤、休闲裤、短裤。
- **版型**：修身、合体、宽松、直筒、阔腿、锥形、A 字、H 型。
- **长度**：短款、常规、中长、长款、九分、七分。
- **面料**：棉、亚麻、羊毛、羊绒、真丝、聚酯、粘纤、锦纶、氨纶。
- **波段/季节**：春一波、夏二波、早秋、深秋、冬一波；以企业配置为准。

## 尺码与颜色归一

- "小码"可能是 S，但必须结合品牌尺码表；"大码"可能是 L、XL 或扩码系列，不能直接映射单一尺码。
- "均码/F"是明确尺码值，不等于所有尺码。
- "二尺一""27 码"等裤装尺码需保留原体系，通过商品尺码表转换。
- "160/84A"是号型，不应只抽取为 `160`。
- 黑/黑色/雅黑可作为候选同义词，但最终使用 ERP 颜色编码。
- 米白/奶白/本白/象牙白不应无条件合并；卡其可能对应浅卡其/深卡其或品牌自定义色。
- 图片颜色受光线影响，只能作为候选条件。

## 模糊指代（口语表达惯例）

- "刚才那个黑色的"：从最近一次唯一商品候选继承款号，只继承颜色。
- "同款大一码"：继承款号和颜色，尺码按该商品尺码序列向上移动一级。
- "另外一个颜色"：必须列出可选颜色，不能随意选择。
- "上次卖得好的裙子"：先按指定时间范围查询销售排行，再让用户选择或使用唯一结果。

### 补货术语

| 术语 | 定义 |
|------|------|
| 补货采购请求 | 对热销款/断码款等缺货 SKU 发起追加采购的动作；提交后生成采购请求，不直接增加库存；对应 `08-replenishment` |
| 补货车 | 本次会话内待提交的补货 SKU 集合（当前会话保留，退出清空） |
| 补货单（SKU采购请求） | 记录补货 SKU、数量、预估金额、供应商（可选）、状态的单据；不直接增加库存；仅指 `08-replenishment` 语境 |
| 采购进货补货单 Tab | 采购进货页中的独立功能，展示平台货品/其他货品购物车，按未处理/已处理/已失效管理；不等同于补货采购请求 |
| 补货数量 | 单 SKU 本次补货件数，1–999 |
| 待补货 | 补货单初始状态，表示补货请求已提交待履约 |
| 已补货 | 补货单已履约（手动标记，或迭代 2 由入库动作联动） |
| 已作废 | 补货单作废状态；仅「待补货」可作废 |
| 预估金额 | 补货单货品小计 = 进价 × 补货数量（进价快照） |

### 平台相似款与平台采购术语（规划）

| 术语 | 定义 |
|------|------|
| 平台货品 | 卖货猫平台商品中心内可供门店采购的货品，不等同于门店本地货品 |
| 平台相似款 | 与门店本地货品图片达到服务端相似度阈值、且满足平台可采购条件的平台货品 |
| 相似度 | 图片相似度服务返回的 `0-100%` 匹配分数；列表按相似度降序展示 |
| 平台购物车 | 当前账号和门店待提交的平台 SKU 集合；独立于 `replenishment-tab` 的购物车 |
| 平台采购请求 | 用户从平台购物车提交给平台的采购数据；提交不直接增加本地库存 |
| 本地货品 | 门店货品管理中维护的货品，拥有本地图片、款号、SKU、价格和库存 |
