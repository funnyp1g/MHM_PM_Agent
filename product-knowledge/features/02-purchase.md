# 功能模块：进货入库

## 基本信息

- **功能模块**：进货入库
- **最后更新**：2026-08-07
- **来源**：《卖货猫app产品使用手册》+《APP页面设计规范及功能位置参考.md》（多店版）
- **相关页面**：`purchase-create` 新建进货单、`purchase-list` 采购进货列表、`purchase-detail` 进货单详情、`replenishment-tab` 采购进货补货单 Tab（详见 `ui/pages.md`）。`replenishment-tab` 是独立于 `features/08-replenishment.md` 的实机功能。

## 功能描述

- **一句话概述**：支持一手货源（珠海小花）对接、商品码/包裹码扫码入库、新建入库单与进货单管理。
- **解决的用户问题**：门店快速进货入库，支持批量对接上游货源。
- **核心场景**："珠海小花订单如何一键入库""怎么新建入库单""扫商品码入库"。

## 能力清单

- **一手入库**：
  - 珠海小花账号关联：首页→进货→账号绑定按钮，输入手机号绑定一手账号。
  - 设置导入内容：勾选导入一手图、一手的品类导入、其他数据导入。
  - 珠海小花订单一键入库：一手订单→切换到进货单→检查商品/款号/价格→入库→结算付款。
  - 珠海小花订单管理：支持按订单/包裹查看，运输中/未发货状态，点货入整单导入，扫快递单条码点货。
- **扫商品码入库**：方法一（首页→进货→扫码入库进页面）；方法二（首页→进货→新建进货单→扫商品码）。
- **扫包裹码入库**：扫描包装袋包裹码入库。
- **新建入库单**：新增进货单→选择供应商、入库日期、备注→添加货品/扫码入库→确定。
- **实机新建进货单**：支持自动匹配供应商开关、必填供应商、入库日期、备注；添加货品方式为扫码入库、选择货品、拍照入库；底部展示合计并提供新增货品/确定。
- **手动添加货品到进货单**：选择货品、增加数量。
- **进货单管理**：进货单/一手订单切换；记录入库/退货数据、应付/实付金额；支持详情、打印、作废。
- **采购进货补货单 Tab（实机独立功能）**：采购进货页第三个 Tab 展示平台货品/其他货品购物车，并按未处理/已处理/已失效管理。它不是 `08-replenishment` 的 SKU 补货采购请求，不复用后者的「待补货/已补货/已作废」状态机。
- **实机入口结构**：进货单页包含「进货单/供应商订单/补货单」三 Tab，列表底部固定「扫码入库/新建进货单/AI智能入库」；每条单据支持下载图片、部分打印、全部打印。
- **入库方式弹层**：首页「进货」先进入选择入库方式弹层，包含一键入库、扫码入库、某花小票、AI智能入库、手动点货入库。

## 关键流程

### 珠海小花订单一键入库

```text
一手订单 -> 切换到一手订单 -> 珠海小花进货单（入库日期、应付金额）
  -> 检查商品、款号、价格无误 -> 入库 -> 进货结算（应付、其他费用）
  -> 点击付款入库成功（可扫码支付）
```

### 扫码入库

```text
方法一：首页 → 进货 → 扫码入库 → 扫描商品码
方法二：首页 → 进货 → 新建进货单 → 扫商品码进行扫码入库
```

## 依赖与关联

- **上游依赖**：珠海小花一手账号绑定；供应商；货品资料。
- **下游影响**：入库增加库存，影响货品列表、库存货值、经营分析。
- **关联功能**：货品管理（入库后货品有库存）、供应商管理（进货单关联供应商）、开单（有库存才能开单）。

## 数据与规则

- 进货单核心字段：供应商、入库日期、备注、货品（款号/进价/售价）、入库数量、应付金额、实付金额。
- 采购进货补货单 Tab 已观察到的字段/状态：货品名称或款号搜索、平台货品/其他货品分类、未处理/已处理/已失效、购物车件数、加入购物车、批量管理。
- 进货单详情还展示支付方式、操作人、创建时间、SKU 的颜色/尺码/数量，并提供作废、复制、打印、编辑。
- 支持商品码、包裹码、珠海小花订单三种入库方式。
- 珠海小花订单入库前需"检查商品、款号、价格无误"，价格以实际为准。

## 已知边界与限制

- 一手货源需先绑定账号并设置导入内容。
- 支持入库、退货两种操作；单据可作废。
