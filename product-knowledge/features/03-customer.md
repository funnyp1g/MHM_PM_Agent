# 功能模块：客户管理与会员营销

## 基本信息

- **功能模块**：客户管理与会员营销
- **最后更新**：2026-08-07
- **来源**：《APP页面设计规范及功能位置参考.md》（多店版）+《卖货猫app产品使用手册》
- **相关页面**：`marketing` 营销页、`customer-list` 客户/会员列表、`customer-detail` 会员详情（详见 `ui/pages.md`）

## 功能描述

- **一句话概述**：营销页承载客户/会员管理与营销工具，支持新增客户、客户列表检索、客户详情（标签/画像/消费记录），以及会员等级/充值/运营与营销活动（优惠券/满减等）。
- **解决的用户问题**：门店沉淀客户资产、追踪消费行为，并通过会员与营销工具提升复购。
- **核心场景**："怎么新增客户""查看客户画像""怎么发优惠券""会员充值"。

## 能力清单

### 营销页（`marketing`）
- **会员模块**：免费会员/付费会员数量概览。
  - 会员等级：管理会员等级。
  - 付费会员：开通/管理付费会员。
  - 积分设置：配置积分规则。
  - 会员充值：会员储值充值。
  - 会员运营：会员营销运营。
  - 群发消息：会员消息群发。
  - 会员码：展示/扫码会员码。
- **营销模块**：自动送券活动/自行创券活动数量概览。
  - 优惠券、消费返现、限时折扣、满减、自动送券、微相册、AI去水印。
- **底部 slogan**：省心赚钱每一天！

### 客户管理（`customer-list`）
- **新增客户**：录入性别、生日、适用价等信息，点击保存完成新增。
- **管理客户**：
  - 搜索：按客户名字或手机号码检索。
  - 列表：客户数量、销售金额；每个客户卡片含名称、电话、消费金额、消费订单数、客单件数。
  - 卡片操作：开单、收起/展开全部数据。
  - 底部：新增用户按钮。
- **客户详情页**：
  - 基本信息：客户名称、电话号码。
  - 最近到店时间。
  - 添加客户标签。
  - 客户画像：基本情况、偏好数据。
  - 消费记录：按时间查看消费与交易订单数据。
  - 客户信息：可编辑客户资料。
- **实机会员管理**：列表顶部显示会员数和销售金额；会员卡片包含姓名、等级、手机号、最近到店、余额、积分、优惠券，并可直接「开单」或「展开」；底部固定「新增用户」。
- **实机会员详情**：摘要区展示消费金额、余额、积分、优惠券；基本情况包含性别、年龄、身高、体重、归属门店；支持近30天/自定义日期筛选、会员偏好区域、编辑资料和开单。

## 关键流程

```text
营销页 -> 会员模块（等级/充值/运营/群发）或营销工具（优惠券/满减等）
新增客户：营销页会员模块 -> 添客/客户列表 -> 新增用户 -> 填写信息 -> 保存
查看详情：客户列表 -> 点击客户 -> 客户详情（标签/画像/消费记录/编辑）
```

## 依赖与关联

- **上游依赖**：货品（消费记录关联商品）、开单（客户开单记录与积分余额）。
- **下游影响**：客户标签、画像支撑精准营销与经营分析；会员等级/营销活动影响开单价格与结算。
- **关联功能**：开单（选择会员）、货品（消费记录）、数据页（会员分析/会员贡献）。

## 数据与规则

- 客户核心字段：姓名、电话（手机号）、性别、生日、适用价、消费金额、消费订单数、客单件数、最近到店时间、标签、积分、余额、会员等级。
- 客户卡片可展开查看全部数据；可直接从卡片发起开单。
- 营销工具（优惠券/满减/限时折扣/消费返现）作用于销售开单结算。

## 已知边界与限制

- 客户详情含画像与消费记录，涉及个人数据，隐私处理遵循行业规范。
- 付费会员为独立能力，与免费会员区分管理。
