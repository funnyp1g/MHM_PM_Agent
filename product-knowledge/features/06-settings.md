# 功能模块：权限配置与系统设置

## 基本信息

- **功能模块**：权限配置与系统设置
- **最后更新**：2026-08-07
- **来源**：《APP页面设计规范及功能位置参考.md》（多店版）+《卖货猫app产品使用手册》
- **相关页面**：`more` 更多功能页、`settings` 系统设置、`settings-permissions` 员工/权限管理、`role-list` 岗位权限、`role-edit` 编辑岗位（详见 `ui/pages.md`）

## 功能描述

- **一句话概述**：低频功能聚合在「更多功能」页（右下角悬浮按钮进入），含店铺设置、员工权限、硬件设备、供应商、库存管理；由店主通过系统设置配置岗位权限与货品通用规则。
- **解决的用户问题**：店主精细化管理店员权限，统一货品定价与运营规则；集中访问低频设置。
- **核心场景**："如何配置岗位权限""货品通用设置""打印设置""库存盘点"。

## 能力清单

### 更多功能页（`more`，分类聚合）
- **常用功能**（可自定义编辑）：货品信息、个性配置、采购退货、员工权限。
- **店铺分类**：门店设置、员工权限、收款方式、分店模式、个性配置、货品信息、店铺收支、定价设置。
- **硬件设备分类**：打印设置、扫码枪。
- **供应商分类**：供应商、采购退货。
- **库存管理分类**：库存盘点、跨店调拨。
- **实机库存盘点**：库存盘点页按进行中/已结束管理盘点计划，支持新增计划、扫码/选货、临时保存和盘点完成。
- **实机跨店调拨**：跨店调拨页按调出/调入管理待入库单据，详情页可核对当前库存并确认入库。
- **实机店铺设置**：门店设置维护 logo、门店名称、地区、地址、微信号、电话和门店微信图片。

### 权限配置（岗位管理）
- 入口：更多功能 → 员工权限/岗位管理。
- 老板账号开放全部功能；店长、店员仅开放部分功能。
- 可配置的权限域至少包括：客户、进货、经营分析、供应商、营销工具、进货单；具体页面、按钮、字段和读写操作仍需按岗位逐项确认。
- 实机默认岗位：老板、店长、店员；店长和店员支持复制、编辑权限、删除，老板不展示同级编辑操作。
- 编辑岗位页面分为「基础权限 / 关键权限」，按首页、客户管理、客户运营、货品、库存管理、销售、微相册、供应商管理、采购进货、采购退货等业务域配置。

### 货品通用设置
- 滞销商品设置：设置滞销天数（可按品类配置）。
- 商品自动停用：设置"天前进货的商品，库存数=0 时自动停用"。

### 货品属性/定价设置
- 商品价格：销售定价、会员定价、进货定价；使用会员价开关；批量设置定价规则（店铺级公式）与取整规则；品类级定价（品类公式优先，单独设置后店铺全局配置失效）。
- 销售单抹零：选择取整规则（小数向上取整、个位向上取整、固定个位数）。

## 关键流程

```text
更多功能：右下角「更多功能」悬浮按钮 -> 更多功能页（常用/店铺/硬件/供应商/库存管理分类）
权限配置：更多功能 -> 员工权限 -> 岗位管理 -> 勾选模块权限
库存盘点：更多功能 -> 库存管理 -> 库存盘点 -> 新增计划 -> 扫码/选货 -> 临时保存或盘点完成
跨店调拨：更多功能 -> 库存管理 -> 跨店调拨 -> 查看待入库单 -> 确认入库
价格规则：更多功能 -> 店铺 -> 定价设置 -> 商品价格 -> 定价公式 + 取整规则
```

## 依赖与关联

- **上游依赖**：账号体系（员工/岗位）。
- **下游影响**：岗位权限控制客户、进货、经营分析、供应商、营销工具、进货单的可见与操作；货品设置影响货品管理与开单。
- **关联功能**：货品管理（滞销/停用/价格）、销售开单（抹零规则）、进货入库、库存盘点/跨店调拨（库存管理）。

## 数据与规则

- 岗位权限模块：客户、进货、经营分析、供应商、营销工具、进货单。
- 滞销天数可按品类配置（如上衣 10 天、裤子 10 天、羊毛衫 15 天）。
- 定价规则：店铺级（批量设置后全部商品同一公式）或品类级（品类公式优先）。
- 取整规则：小数向上取整、个位向上取整、固定个位数（如固定个位数 8）。

## 已知边界与限制

- 仅店主可进行权限配置。
- 品类级定价"单独设置后店铺全局配置失效"。
- 多店版支持分店模式与跨店调拨（分店相关能力为多店版特有）。
