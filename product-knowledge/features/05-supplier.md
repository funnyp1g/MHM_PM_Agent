# 功能模块：供应商管理

## 基本信息

- **功能模块**：供应商管理
- **最后更新**：2026-08-07
- **来源**：《卖货猫app产品使用手册》+《APP页面设计规范及功能位置参考.md》（多店版）
- **相关页面**：`supplier-list` 供应商管理、`supplier-detail` 供应商详情（入口位于更多功能页→供应商，详见 `ui/pages.md`）

## 功能描述

- **一句话概述**：管理供应商资料，支持列表检索、新增供应商、修改供应商信息。
- **解决的用户问题**：门店维护供货渠道，关联进货单与货品来源。
- **核心场景**："怎么新增供应商""怎么修改供应商信息"。

## 能力清单

- **供应商列表**：
  - 搜索栏：按供应商名称、手机号检索。
  - 列表：展示供应商名称、电话、余额、欠款。
  - 操作：点击进入详情页；左滑停用/启用；底部"新增供应商"按钮。
- **新增供应商**：填写名称、手机号等信息，点击保存。
- **修改供应商信息**：供应商列表→进入详情页→点击编辑→修改各项信息→保存。
- **实机供应商详情**：展示名称、手机号、微信、余额、欠款、地区、市场、详细地址、备注，底部固定「编辑」。

## 关键流程

```text
新增供应商：更多功能页 -> 供应商分类 -> 供应商列表 -> 新增供应商 -> 填名称/手机号 -> 保存
修改信息：供应商列表 -> 进入详情页 -> 编辑 -> 修改 -> 保存
```

## 依赖与关联

- **上游依赖**：暂无。
- **下游影响**：供应商被货品（进货价来源）与进货单（进货单关联供应商）引用。
- **关联功能**：货品管理（供应商属性）、进货入库（进货单供应商）。

## 数据与规则

- 供应商核心字段：名称、手机号、余额、欠款、状态（启用/停用）。
- 列表可搜索、可停用/启用；详情可编辑。

## 已知边界与限制

- 供应商余额与欠款在列表展示，支持启用/停用。
