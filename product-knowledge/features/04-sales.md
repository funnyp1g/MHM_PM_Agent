# 功能模块：销售开单

## 基本信息

- **功能模块**：销售开单
- **最后更新**：2026-08-07
- **来源**：《APP页面设计规范及功能位置参考.md》（多店版）+《卖货猫app产品使用手册》
- **相关页面**：`sales-create` 开单页、`sales-list` 销售单列表（详见 `ui/pages.md`）

## 功能描述

- **一句话概述**：提供完整的收银开单流程，包括选会员、价格类型、整单打折、选品、赠品、欠货、挂单、退货、收银结算与销售单管理。
- **解决的用户问题**：店员快速完成门店收银，灵活处理优惠、欠货、退货等复杂场景。
- **核心场景**："怎么开单""怎么退货""设置欠货""怎么打印小票"。
- **入口**：首页卖货卡片右上角红色胶囊「开单」按钮，直达开单页。

## 能力清单

- **开单页（`sales-create`）**：
  - 会员信息栏：展示当前会员（如"阿里 普通会员"）与积分/余额，点击「>」选择会员。
  - 价格类型：下拉选择（默认销售价，可切换会员价等）。
  - 整单打折：下拉设置（默认不打折）。
  - 添加货品三种方式：手机扫码、+选择货品、扫码枪（可显示未连接）。
  - 商品行：货品名/款号/规格/销售价/实收价；每行右侧「赠品」「欠货」标签按钮（选中红色）与「🗑」删除、「✎」改价。
  - 底部固定结算栏：售 X 件/退 X 件、应收金额、优惠金额、查看明细、红色胶囊「去收银」。
- **挂单**：顶部「挂单」保留当前数据，可稍后继续开单；销售单列表查看挂单列表，点击编辑继续开单。
- **退货**：选择货品减成负数（或编辑成负数）表示退货；退货商品不可设为欠货商品。
- **修改应收金额**：点击应收金额处输入修改；其他费用输入后应收金额增加。
- **抹零**：支持抹小数、抹个位；少收金额算优惠。
- **新增收银账户**：输入账户名称、选择账户类型（银行卡、支付宝等），新增后排第一位。
- **组合收款**：开启组合收款，可修改金额，支持银行卡、支付宝等多个账户组合。
- **销售单抹零规则**：系统设置配置取整规则（小数向上取整、个位向上取整、固定个位数，如应收 188.50 → 190）。
- **查看单据金额明细**：结算成功/详情页面点击明细；销售单列表点击展开按钮。
- **打印小票**：结算页面滑到底部打印；销售单列表/详情页点击打印。
- **管理销售单（`sales-list`）**：查看挂单数量、销售/退货/总金额/实收金额、开单人/单号/日期；左滑订单作废；底部开单按钮。
- **实机销售单列表**：包含「销售单/销售明细/充值单」三 Tab，支持按姓名、会员、电话、款号、备注查询，按销售时间、销售数量、实收金额、创建时间排序；零数据时展示空态，底部固定「开单」。
- **结算页（`checkout`）**：展示应收、实收、抹零/取整、其他费用、积分开关、组合渠道、会员余额及 POS/银行卡、欠款账户、现金、支付宝等收款渠道；底部「确认收款」会产生真实收款结果。

## 关键流程

### 开单主流程

```text
首页卖货卡片「开单」 -> 开单页
  -> （可选）选择会员 -> 设置价格类型/整单打折
  -> 扫码/选择货品添加商品（可设赠品/欠货）
  -> 底部结算栏核对（售/退件数、应收、优惠）
  -> 去收银 -> 支付方式（可改应收/其他费用/抹零/组合收款）
  -> 确认收款 -> 开单成功 -> 销售单列表
```

### 退货

```text
开单页选择货品 -> 减成负数（或编辑成负数）-> 表示退货
```

## 依赖与关联

- **上游依赖**：货品（选品/价格/库存）、客户/会员（会员信息栏）、开单人、收银账户。
- **下游影响**：开单成功后更新销售数据、库存、客户消费记录；进入数据页经营分析。
- **关联功能**：货品管理（选品与价格）、客户管理（开单关联客户）、进货入库（库存来源）、首页（卖货卡片数据）。

## 数据与规则

- 销售单核心字段：开单人、开单时间、商品（数量/价格）、应收金额、实收金额、其他费用、抹零、支付方式、赠品、欠货标识、退货标识、会员。
- 退货=负数量商品；退货商品不可设欠货。
- 抹零与取整规则：可配置小数向上取整/个位向上取整/固定个位数；少收金额算优惠。
- 组合收款可多账户拆分应收金额。
- 挂单保留当前开单数据，可恢复继续开单。

## 已知边界与限制

- 退货、作废、修改均通过负数量/左滑操作完成。
- 欠货商品需在开单时标记，退货商品除外。
- 开单页商品行使用标签按钮式状态（赠品/欠货），非下拉选择。
