# APP 页面设计规范及功能位置参考

> 服装零售门店管理/收银APP（多店版）设计基准文档

---

## 一、APP 整体定位与架构

### 产品定位
面向服装零售门店的**多店版进销存+收银+会员营销一体化管理系统**，核心用户为服装店老板/店长/店员。

### 顶部主导航（三大 Tab）

| Tab | 位置 | 核心功能 |
|-----|------|----------|
| **首页** | 顶部左 | 今日数据概览仪表盘 |
| **数据** | 顶部中 | 销售/库存/利润等深度数据分析 |
| **营销** | 顶部右 | 会员管理 + 营销工具 |

### 全局悬浮入口
- **右下角**：圆形红色「更多功能」悬浮按钮（贯穿首页/数据/营销三页）

## 二、设计规范

### 1. 颜色系统

| 用途 | 颜色 | 色值参考 | 应用场景 |
|------|------|----------|----------|
| **主色** | 珊瑚红渐变 | `#FF5A5F` → `#FF7E67` | 顶部导航栏、选中Tab、主按钮、强调数据 |
| **辅助色-绿** | 翠绿色 | `#07C160` | 正向增长数据（环比↑）、会员相关图标 |
| **辅助色-蓝** | 浅蓝色 | `#4A90E2` | "货"分类标签、货品相关图标 |
| **辅助色-橙** | 暖橙色 | `#FF9500` | "利"利润标签、进货/供应商相关 |
| **辅助色-紫** | 蓝紫色 | `#5B6DFF` | 营业汇总等数据图标 |
| **背景色** | 浅灰白 | `#F0F2F5` | 页面整体背景 |
| **卡片色** | 纯白 | `#FFFFFF` | 各功能模块卡片 |
| **主文字** | 深灰黑 | `#333333` | 标题、核心数据 |
| **次文字** | 中灰色 | `#666666` | 说明文字、指标标签 |
| **弱文字** | 浅灰色 | `#999999` | 辅助说明、时间戳 |
| **分割线** | 极浅灰 | `#EEEEEE` | 列表分隔、卡片内部分隔 |

### 2. 字体与排版

- **字体**：系统默认无衬线字体（苹方/思源黑体）
- **层级规则**：
  - 页面大标题：18-20px，粗体
  - 卡片标题：16-17px，粗体 + 彩色图标
  - 数据数字：22-28px，常规字重，醒目突出
  - 指标标签：12-13px，灰色
  - 列表正文：14-15px

### 3. 布局与间距

- **顶部导航栏高度**：约 180px（含状态栏 + 店铺信息栏 + Tab栏）
- **卡片圆角**：12-16px 大圆角
- **卡片内边距**：左右 16px，上下 20px
- **页面左右边距**：12-16px
- **模块间距**：12-16px（卡片与卡片之间）
- **数据网格**：三列等分布局（卖货/进货/会员卡片内）

### 4. 核心组件样式

| 组件 | 样式特征 |
|------|----------|
| **主按钮** | 红色填充 + 圆角胶囊形 + 白色文字 |
| **次要按钮** | 浅灰背景 + 圆角胶囊形 + 深灰文字 |
| **标签/徽章** | 圆角矩形 + 浅色背景 + 彩色文字（如"开单""赠品""欠货"） |
| **功能图标** | 面性图标 + 渐变色填充（红/橙/绿/蓝/紫），圆形或圆角方形底 |
| **列表行** | 左侧指标名 + 右侧数值，底部细分割线 |
| **下拉选择** | 文字 + 向下箭头 ▼ |
| **开关/状态** | 红色文字表示选中/激活态 |

## 四、交互模式总结

| 交互模式 | 说明 |
|----------|------|
| **顶部Tab切换** | 首页/数据/营销 三页通过顶部Tab横向切换 |
| **卡片详情跳转** | 每个数据卡片右上角有「详情>」按钮，点击进入详情页 |
| **快捷操作按钮** | 卡片右上角有红色胶囊按钮（开单/进货/添客/建款），直达核心操作 |
| **右下角悬浮按钮** | 「更多功能」常驻悬浮，点击进入全功能列表 |
| **日期选择器** | 数据页统一顶部日期选择，支持环比/同比切换 |
| **列表左滑删除** | 开单页商品行右侧有删除图标 |
| **状态标签切换** | 商品行支持赠品/欠货状态切换（按钮式） |
| **底部固定结算栏** | 开单页底部固定显示合计 + 去收银主按钮 |

## 五、页面功能清单速查

### 首页（仪表盘）
- 店铺切换 / 日历
- 通知横幅
- 日期选择（编辑/展示/说明）
- 卖货数据卡片（订单、销售件数、营业额、客单价、连带率、客单数、单笔最多、单笔最高）
- 进货数据卡片（款数、件数、合计）
- 会员数据卡片（总数、新增、复购）
- 货品数据卡片（总数、增加、减少）

### 数据页
- 5大分析入口：销售&利润、货品分析、会员分析、店员业绩、营业汇总
- 日期选择 + 环比/同比切换 + 导出
- 销售趋势折线图
- 销售数据对比表（销售数、销售额、销售笔数、抹零）
- 库存数据对比表（库存数、库存价值、进货数、进货额、进货笔数、退货数、退货额、滞销数）
- 利润数据对比表（毛利润）

### 营销页
- 会员模块：会员等级、付费会员、积分设置、会员充值、会员运营、群发消息、会员码
- 营销模块：优惠券、消费返现、限时折扣、满减、自动送券、微相册、AI去水印

### 更多功能页
- 常用功能（可自定义）
- 店铺类：门店设置、员工权限、收款方式、分店模式、个性配置、货品信息、店铺收支、定价设置
- 硬件设备：打印设置、扫码枪
- 供应商：供应商、采购退货
- 库存管理：库存盘点、跨店调拨

### 开单页
- 挂单功能
- 会员信息（积分、余额）
- 价格类型选择
- 整单打折
- 添加货品：手机扫码 / 选择货品 / 扫码枪
- 商品列表（赠品、欠货、删除、修改价格）
- 底部结算：售/退件数、应收金额、优惠、去收银
