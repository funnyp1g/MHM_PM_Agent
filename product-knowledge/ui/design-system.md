# 设计系统规范

> 来源：《APP页面设计规范及功能位置参考.md》（多店版，2026-08-07）。PRD「页面与交互」章节与新增页面的视觉/组件必须遵循本规范，不自行发明样式。
> 原始文档：`ui/source/APP页面设计规范及功能位置参考.md`

## 产品架构

- **顶部主导航（三大 Tab）**：首页（左）/ 数据（中）/ 营销（右），横向切换。
- **全局悬浮入口**：右下角圆形红色「更多功能」悬浮按钮，贯穿首页/数据/营销三页，点击进入全功能列表。

## 颜色系统

| 用途 | 颜色 | 色值参考 | 应用场景 |
|------|------|----------|----------|
| 主色 | 珊瑚红渐变 | `#FF5A5F` → `#FF7E67` | 顶部导航栏、选中Tab、主按钮、强调数据 |
| 辅助色-绿 | 翠绿色 | `#07C160` | 正向增长数据（环比↑）、会员相关图标 |
| 辅助色-蓝 | 浅蓝色 | `#4A90E2` | "货"分类标签、货品相关图标 |
| 辅助色-橙 | 暖橙色 | `#FF9500` | "利"利润标签、进货/供应商相关 |
| 辅助色-紫 | 蓝紫色 | `#5B6DFF` | 营业汇总等数据图标 |
| 背景色 | 浅灰白 | `#F0F2F5` | 页面整体背景 |
| 卡片色 | 纯白 | `#FFFFFF` | 各功能模块卡片 |
| 主文字 | 深灰黑 | `#333333` | 标题、核心数据 |
| 次文字 | 中灰色 | `#666666` | 说明文字、指标标签 |
| 弱文字 | 浅灰色 | `#999999` | 辅助说明、时间戳 |
| 分割线 | 极浅灰 | `#EEEEEE` | 列表分隔、卡片内部分隔 |

## 字体与排版

- **字体**：系统默认无衬线字体（苹方/思源黑体）。
- **层级规则**：
  - 页面大标题：18-20px，粗体
  - 卡片标题：16-17px，粗体 + 彩色图标
  - 数据数字：22-28px，常规字重，醒目突出
  - 指标标签：12-13px，灰色
  - 列表正文：14-15px

## 布局与间距

- 顶部导航栏高度：约 180px（含状态栏 + 店铺信息栏 + Tab栏）。
- 卡片圆角：12-16px 大圆角。
- 卡片内边距：左右 16px，上下 20px。
- 页面左右边距：12-16px。
- 模块间距：12-16px（卡片与卡片之间）。
- 数据网格：三列等分布局（卖货/进货/会员卡片内）。

## 核心组件样式

| 组件 | 样式特征 |
|------|----------|
| 主按钮 | 红色填充 + 圆角胶囊形 + 白色文字 |
| 次要按钮 | 浅灰背景 + 圆角胶囊形 + 深灰文字 |
| 标签/徽章 | 圆角矩形 + 浅色背景 + 彩色文字（如"开单""赠品""欠货"） |
| 功能图标 | 面性图标 + 渐变色填充（红/橙/绿/蓝/紫），圆形或圆角方形底 |
| 列表行 | 左侧指标名 + 右侧数值，底部细分割线 |
| 下拉选择 | 文字 + 向下箭头 ▼ |
| 开关/状态 | 红色文字表示选中/激活态 |

## 交互模式

| 交互模式 | 说明 |
|----------|------|
| 顶部Tab切换 | 首页/数据/营销 三页通过顶部Tab横向切换 |
| 卡片详情跳转 | 每个数据卡片右上角有「详情>」按钮，点击进入详情页 |
| 快捷操作按钮 | 卡片右上角红色胶囊按钮（开单/进货/添客/建款），直达核心操作 |
| 右下角悬浮按钮 | 「更多功能」常驻悬浮，点击进入全功能列表 |
| 日期选择器 | 数据页统一顶部日期选择，支持环比/同比切换 |
| 列表左滑删除 | 开单页商品行右侧有删除图标（🗑） |
| 状态标签切换 | 商品行支持赠品/欠货状态切换（按钮式标签） |
| 底部固定结算栏 | 开单页底部固定显示合计 + 去收银主按钮 |

## 页面设计原则

1. **数据仪表盘化**：首页/数据页以「数据卡片」组织，卡片内三列等分网格，右上角「详情>」进入细分。
2. **直达式快捷操作**：核心动作（开单/进货/添客/建款）以红色胶囊按钮直接暴露在卡片右上角。
3. **分类聚合入口**：低频功能集中在「更多功能」页按分类聚合（店铺/硬件设备/供应商/库存管理）。
4. **状态可视化**：正负变化用绿（↑）/红标注，标签用浅色底+彩色字。
