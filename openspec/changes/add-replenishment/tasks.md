## 2. 数据模型与接口

- [ ] 2.1 新增补货单（ReplenishmentOrder）数据模型：单号、供应商(可选)、创建人、创建时间、状态、备注(可选)、明细列表
- [ ] 2.2 新增补货单明细（ReplenishmentItem）：SKU、货品名称、款号、颜色/尺码、当前库存快照、补货数量、进价快照、预估金额
- [ ] 2.3 实现补货单状态枚举（待补货/已补货/已作废）与状态流转校验（仅待补货可作废）
- [ ] 2.4 实现选品接口：按名称/款号/条码搜索、品类/品牌筛选、返回 SKU 与库存/价格，过滤已停用货品
- [ ] 2.5 实现补货单创建接口：入参为补货车明细与供应商(可选)/备注，幂等防重，成功返回补货单号
- [ ] 2.6 实现补货单查询接口：列表（时间倒序、状态筛选）与详情
